# a vertical farming game

## developed in godot 4.3
i had 2 weeks to develop an innovative solution to the United Nations SDG 2: Zero Hunger for a school project

so i said welp why don't i make a game

it contains about 7 bajillion lines of highly sophisticated farming simulation technology*

<sub>*this number may be slightly inaccurate due to the inherent limitations of line counting software</sub>

you can play the game at lem0nmel0n.github.io/vertical-farming :]

## source code
it's public (yay!)

explaining my code through comments was worth additional marks.
i therefore took this assignment extremely seriously.
perhaps too seriously.

the code includes extensive commentary explaining variables, functions, data structures, conditionals, royal titles, crop harvesting, and all the necessary components of the vertical farming experience.

at this point there's probably more comments than code.

if you can be bothered, please read the source files.

## known features
- crop harvesting
- money increasing
- labels displaying instructions
- people who eat an abnormal amount of lettuce
- fruit drawings
- requests from customers
